Muster erkannt? Immer wenn eine Bedingung erfüllt ist, passiert etwas – sonst etwas anderes (oder nichts). Genau das bringen wir dem Computer jetzt bei!

Die einfachste if-Anweisung

// Allgemeine Form if (Bedingung) { // wird nur ausgeführt, // WENN die Bedingung wahr ist }
// Konkretes Beispiel int alter = 15; if (alter >= 16) { System.out.println("Du darfst den Moped-Führerschein machen!"); }
💡 Lies es wie einen Satz: „WENN alter mindestens 16 ist, DANN gib den Text aus.“ Die geschweiften Klammern { } umschließen alles, was bei „wahr“ passieren soll.

if im Tierheim: Die Fütterung

Zurück zu unserer Tier-Klasse – die Fütterung soll nur hungrige Tiere füttern:

// Neue Attribute in der Klasse Tier private boolean hungrig = true; // Die Methode fressen wird schlauer public void fressen() { if (hungrig == true) { System.out.println(name + " frisst. Lecker!"); hungrig = false; } }
💡 Das Attribut hungrig ist vom Typ boolean – es kann nur true (wahr) oder false (falsch) sein. Nach dem Fressen ist das Tier satt, also wird hungrig auf false gesetzt.
Teste dein Verständnis: Was passiert, wenn mimi.fressen() zweimal hintereinander aufgerufen wird? Warum?

Achtung, Klassiker: = ist eine Zuweisung (nameStart = "Bello"), == ist ein Vergleich (alter == 16). Verwechseln = Lieblingsfehler von Anfängern und Profis! 😉

if – else: Zwei Wege

Oft soll bei „falsch“ auch etwas passieren – dafür gibt es else:

// Beispiel: Tierheim-Eintritt int alter = 12; if (alter >= 14) { System.out.println("Du darfst allein ins Tierheim."); } else { System.out.println("Bitte komm mit einer erwachsenen Person."); }
💡 else bekommt keine eigene Bedingung! Es ist einfach der sonst-Fall: Es greift genau dann, wenn die if-Bedingung falsch ist. Genau einer der beiden Blöcke wird immer ausgeführt.

else if: Mehrere Fälle nacheinander

Die Tierheim-Statistik soll die Tiere in Kategorien einteilen:

// Note für den Gesundheitszustand if (gewicht < 5) { System.out.println(name + " braucht extra Futter."); } else if (gewicht < 15) { System.out.println(name + " ist topfit!"); } else if (gewicht < 25) { System.out.println(name + " sollte mehr Bewegung machen."); } else { System.out.println(name + " braucht einen Diätplan."); }
💡 Java prüft die Bedingungen von oben nach unten – sobald eine wahr ist, wird ihr Block ausgeführt und alle weiteren werden übersprungen. Das else am Ende fängt alles auf, was vorher nicht gepasst hat.

Vier Klassiker-Fehler

= statt ==

if (alter = 16) ❌  →  if (alter == 16) ✓

Semikolon nach if

if (a > b); { ... } ❌  →  das ; beendet die if-Anweisung sofort – der Block läuft dann immer!

Vergessene Klammern

Zur einzelnen Anweisung dürfen die { } wegfallen – aber lieber immer setzen! Sonst überraschen dich später Fehler.

Text vergleichen mit ==

Für Strings nimmt man name.equals("Bello") statt name == "Bello".
