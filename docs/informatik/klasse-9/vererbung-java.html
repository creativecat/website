Schritt 4: Vom Diagramm zum Code

Erst die Superklasse – dann die Subklasse mit extends:

// Die Superklasse public class Tier { private String name; private String rasse; private int alter; public Tier(String nameStart, String rasseStart, int alterStart) { name = nameStart; rasse = rasseStart; alter = alterStart; } public void fressen() { System.out.println(name + " frisst. Lecker!"); } }
// Die Subklasse – Hund IST EIN Tier public class Hund extends Tier { public Hund(String nameStart, String rasseStart, int alterStart) { super(nameStart, rasseStart, alterStart); } public void bellen() { System.out.println("Wuff!"); } }

Achte auf zwei Neuerungen: extends Tier in der Kopfzeile und super(...) im Konstruktor – es ruft den Konstruktor der Superklasse auf.

Die Katze – und der erste Test

public class Katze extends Tier { public Katze(String nameStart, String rasseStart, int alterStart) { super(nameStart, rasseStart, alterStart); } public void miauen() { System.out.println("Miau!"); } }
// In der main-Methode: Hund bello = new Hund( "Bello", "Labrador", 3); Katze mimi = new Katze( "Mimi", "Europäisch", 2); bello.fressen(); // geerbt! bello.bellen(); mimi.fressen(); // auch geerbt! mimi.miauen();
Genial: fressen() haben wir nur einmal geschrieben – beide Tiere können es trotzdem!

Bonus: Methoden überschreiben

Alle Tiere sollen lautGeben() können – aber jedes anders! In der Superklasse allgemein definieren, in den Subklassen überschreiben:

// In der Superklasse Tier public void setName(String nameNeu) { name = nameNeu; } public void lautGeben() { System.out.println("..."); // allgemein }
// In der Subklasse Hund @Override public void lautGeben() { System.out.println( "Wuff! Wuff!"); }
Regel: Gleicher Methodenname, gleiche Parameter – aber neuer Inhalt in der Subklasse. @Override kennzeichnet das Überschreiben.
