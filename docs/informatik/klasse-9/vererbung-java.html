Schritt 3: Die Lösung – eine Superklasse!

Gold = gemeinsam in Tier zusammengefasst → wird an Hund und Katze vererbt. Jede Subklasse hat ihren eigenen Pfeil mit hohlem Dreieck zur Superklasse.

Fachbegriffe: Tier = Superklasse (Elternklasse) · Hund, Katze = Subklassen (Kindklassen). Der Pfeil zeigt in UML immer von der Subklasse zur Superklasse.

Schritt 4: Die Superklasse programmieren

// Tier.java – die Superklasse mit allem Gemeinsamen public class Tier { // Attribute private String name; private String rasse; private int alter; // Konstruktor public Tier(String nameStart, String rasseStart, int alterStart) { name = nameStart; rasse = rasseStart; alter = alterStart; } // gemeinsame Methode für alle Tiere public void fressen() { System.out.println(name + " frisst. Lecker!"); } }
💡 nameStart, rasseStart, alterStart: Die Parameter tragen den Zusatz „Start“ – so siehst du sofort, dass sie im Konstruktor an die Objektvariablen name, rasse, alter übergeben werden.

Die Subklasse: Hund IST EIN Tier

// Hund.java – erbt mit extends alles von Tier public class Hund extends Tier { // Konstruktor: reicht die Werte an Tier weiter public Hund(String nameStart, String rasseStart, int alterStart) { super(nameStart, rasseStart, alterStart); } // eigene Methode – nur der Hund kann das public void bellen() { System.out.println("Wuff! Wuff!"); } }
💡 extends Tier: Hund erbt alle Attribute und Methoden von Tier.  ·  super(...): ruft den Konstruktor der Superklasse auf – die Attribute werden also in Tier verwaltet.

Der erste Test

// Katze.java – auch die Katze erbt von Tier public class Katze extends Tier { public Katze(String nameStart, String rasseStart, int alterStart) { super(nameStart, rasseStart, alterStart); } public void miauen() { System.out.println("Miau!"); } }
// Test in der main-Methode Hund bello = new Hund("Bello", "Labrador", 3); Katze mimi = new Katze("Mimi", "Europäisch", 2); bello.fressen(); // "Bello frisst. Lecker!" → geerbt! bello.bellen(); // "Wuff! Wuff!" mimi.fressen(); // "Mimi frisst. Lecker!" → auch geerbt! mimi.miauen(); // "Miau!"
Genial: fressen() haben wir nur einmal in Tier geschrieben – beide Tiere können es trotzdem!

Bonus: Methoden überschreiben

Alle Tiere sollen lautGeben() können – aber jedes anders!

// In der Superklasse Tier: allgemein definieren public void lautGeben() { System.out.println("..."); }
// In der Subklasse Hund: neu überschreiben @Override public void lautGeben() { System.out.println("Wuff! Wuff!"); }
Regel: Gleicher Methodenname, gleiche Parameter – aber neuer Inhalt in der Subklasse. @Override kennzeichnet das Überschreiben.
