Schritt 2: Das Entdeckermuster 🔍

Vergleichen wir die beiden Klassen systematisch:

gemeinsame Methodefressen()fressen() → identisch!

Erkenntnis: Die Attribute und fressen() sind komplett doppelt. Bei 20 Tierarten wäre das 20-mal derselbe Code – mühsam, fehleranfällig und schwer zu pflegen!

💡 Profis nennen das Redundanz – und es gilt: „Don't repeat yourself!"

Fachbegriffe: Tier = Superklasse / Elternklasse Hund, Katze = Subklassen / Kindklassen
Die Subklassen erben alle Attribute und Methoden der Superklasse – sie müssen sie nicht noch einmal hinschreiben.

Schritt 4: Vom Diagramm zum Code

Erst die Superklasse, dann eine Subklasse mit extends:

public class Tier {
    private String name;
    private String rasse;
    private int alter;

    public Tier(String name, String rasse, int alter) {
        this.name = name;
        this.rasse = rasse;
        this.alter = alter;
    }

    public void fressen() {
        System.out.println(name + " frisst. Lecker!");
    }
}
public class Hund extends Tier {      // Hund IST EIN Tier

    public Hund(String name, String rasse, int alter) {
        super(name, rasse, alter);      // ruft den Konstruktor der Superklasse auf
    }

    public void bellen() {
        System.out.println("Wuff! Wuff!");
    }
}

Achte auf die zwei Neuerungen: extends Tier in der Kopfzeile und super(...) im Konstruktor.

Die Katze – und der erste Test

public class Katze extends Tier {

    public Katze(String name, String rasse, int alter) {
        super(name, rasse, alter);
    }

    public void miauen() {
        System.out.println("Miau!");
    }
}
// In der main-Methode:
Hund bello = new Hund("Bello", "Labrador", 3);
Katze mimi = new Katze("Mimi", "Europäisch", 2);

bello.fressen();   // "Bello frisst. Lecker!"  ← geerbt von Tier!
bello.bellen();    // "Wuff! Wuff!"
mimi.fressen();    // "Mimi frisst. Lecker!"  ← auch geerbt!
mimi.miauen();     // "Miau!"
Genial: fressen() haben wir nur einmal geschrieben – beide Tiere können es trotzdem!

Bonus: Methoden überschreiben 🔧

Jedes Tier macht ein anderes Geräusch – aber alle sollen lautGeben() können! Lösung: in der Superklasse allgemein definieren, in den Subklassen überschreiben.

public class Tier {
    ...
    public void lautGeben() {
        System.out.println("...");            // allgemein
    }
}

public class Hund extends Tier {
    @Override                            // kennzeichnet das Überschreiben
    public void lautGeben() {
        System.out.println("Wuff! Wuff!");
    }
}
Regel: Gleicher Methodenname, gleiche Parameter – aber neuer Inhalt in der Subklasse. @Override ist dabei ein hilfreicher Hinweis an den Compiler.
