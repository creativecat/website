1 · Funktionale Modellierung

Funktionen

Daten verarbeitende Prozesse mit mehreren Eingaben und einer Ausgabe werden zu Funktionen abstrahiert – auch als Verkettung gegebener Funktionen.

Datenflussdiagramme

Datenflüsse werden mithilfe von Datenflussdiagrammen modelliert: Ein- und Ausgabe, Verteiler, Repräsentation einer Funktion.

Automatisierung

Datenflussdiagramme und Funktionen werden in Formeln eines Tabellenkalkulationssystems umgesetzt – Modell und Umsetzung werden durch geeignete Eingaben überprüft.

1 · Tabellenkalkulation

Praxisnahe Aufgabenstellungen (z. B. aus dem kaufmännischen Bereich oder der Mathematik) werden funktional gelöst und mit einem Tabellenkalkulationsprogramm realisiert.

  • Tabellenblatt, Zelle, Formel, Funktion
  • Vordefinierte Funktionen, auch bedingte Funktionen (z. B. WENN)
  • Zellbezug: relative und absolute Adressierung
  • Verkettung von Funktionen, Parameter
  • Sinnvolle Nutzung von Adressierung und passende Gestaltung

2 · Datenmodellierung & Datenbanken

OO-Datenmodell

Datenbestände aus der Praxis (z. B. Mitgliederverzeichnis) objektorientiert modellieren: Objekt, Klasse, Attribut.

Relationales Modell

OO-Datenmodelle werden in Tabellenschemata überführt und in einem Datenbanksystem umgesetzt: Tabellenschema, Primärschlüssel, Datentyp, Datensatz.

Datenbanksystem

Relationale Datenbank, Datenbankmanagementsystem (DBMS), Mehrbenutzerbetrieb – Abfragen als Funktionen, Ergebnistabellen als Ergebnis einer Abfrage.

2 · SQL-Abfragen

SELECT

Auswahl der Spalten, die angezeigt werden sollen

FROM

Festlegung der Tabelle, aus der gelesen wird

WHERE

Bedingungen zum Filtern der Datensätze – auch verknüpft (AND, OR)

Ziel

Zielgerichtet Informationen aus einer Datenbanktabelle gewinnen

// Beispiel: alle Mitglieder aus Nürnberg SELECT name, vorname FROM Mitglied WHERE ort = 'Nürnberg' AND beitragBezahlt = true;

3 · Objektorientierte Modellierung

Objekt & Klasse

Objekte aus der Erfahrungswelt (z. B. Fahrzeuge, Personen) werden hinsichtlich Eigenschaften (Attribute) und Fähigkeiten (Methoden) analysiert und zu Klassen abstrahiert – grafisch als Klassendiagramm dargestellt.

Algorithmen & Zustände

Kontrollstrukturen, Algorithmen in grafischer Darstellung und Pseudocode, Wertzuweisungen als Zustandsänderung eines Objekts; Datentypen: ganze Zahlen, Gleitkommazahlen, Wahrheitswerte, Zeichen, Zeichenketten.

Methoden

Methodendefinition vs. Methodenaufruf, Parameter und Übergabewerte, Rückgabewert, Konstruktor als spezielle Methode, getter-/setter-Methoden – auch fremde Algorithmen analysieren, interpretieren und modifizieren.

3 · Programmieren in Java

An der Peter-Fischer-Schule wird die objektorientierte Programmierung in Java umgesetzt: Klassen deklarieren, Attribute und Methoden implementieren, Objekte erzeugen.

  • Klassendeklaration mit Attributen und Methoden
  • Konstruktor zum Erzeugen von Objekten
  • Wertzuweisung als Zustandsänderung
  • Methoden anderer Klassen nutzen
public class Fahrzeug { private String kennzeichen; private double geschwindigkeit; public Fahrzeug(String kz) { this.kennzeichen = kz; this.geschwindigkeit = 0; } public void beschleunigen(double delta) { geschwindigkeit = geschwindigkeit + delta; } }

3 · Generalisierung & Vererbung

Oberklasse (Generalisierung)
Unterklasse (Spezialisierung)
Idee
Gemeinsame Eigenschaften mehrerer Klassen zusammenfassen
Erbt Attribute und Methoden, ergänzt eigene
Beispiel
Fahrzeug: kennzeichen, geschwindigkeit
PKW: sitzplätze · LKW: ladefläche
Methoden
Allgemeines Verhalten definieren
Methoden überschreiben für eigenes Verhalten
Java
class Fahrzeug { ... }
class PKW extends Fahrzeug { ... }

Klassendiagramme einfacher Generalisierungshierarchien aus der Erfahrungswelt modellieren und in Java umsetzen.

4 · Datenschutz

Datenschutzgesetze

Zweck, Grundsätze (z. B. Verbotsprinzip mit Erlaubnisvorbehalt), Rechte von Betroffenen

Persönliche Daten

Schutz personenbezogener Daten – insbesondere bei der Mehrbenutzerproblematik von Datenbanken

Datenmissbrauch

Z. B. Identitätsdiebstahl; Schutz persönlicher Daten erhöhen, Gefahr des Missbrauchs minimieren

Data-Mining

Chancen und Risiken automatisierter Analyse großer Datenbestände gesellschaftlich bewerten

  • Datenschutz im Spannungsfeld zwischen Persönlichkeitsrechten und wirtschaftlichen sowie öffentlichen Interessen (z. B. Fahndung nach Straftätern) bewerten
  • Internet verantwortungsvoll nutzen: datenbankgestützte Dienste und Portale kriteriengeleitet abwägen, Medienwirkung (Messenger, soziale Netzwerke) reflektieren

Zusammenfassung

Funktionale Modellierung: Funktionen, Datenflussdiagramme, Verkettung – umgesetzt in der Tabellenkalkulation (relative/absolute Adressierung)

Datenmodellierung: OO-Datenmodell → Tabellenschema → Datenbank; SQL-Abfragen mit SELECT, FROM, WHERE

Objektorientierung: Klassen, Attribute, Methoden, Konstruktoren – implementiert in Java

Vererbung: Generalisierung/Spezialisierung, Ober-/Unterklasse, Methoden überschreiben

Datenschutz: Gesetze, personenbezogene Daten, Datenmissbrauch, Data-Mining bewerten
